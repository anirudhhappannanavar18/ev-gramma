# EV-Grama (Electric Vehicle Grama) ⚡🚗

**Empowering Rural & Semi-Urban India with Community-Driven EV Charging.**

EV-Grama is a decentralized charging platform designed to solve "Range Anxiety" in areas where official charging infrastructure is scarce. It connects EV drivers with local "Hosts"—individuals, shopkeepers, or homeowners—who share their private charging points for a small fee.

## 🌟 Features

- **Dual-Mode System**: Switch easily between **User** (Driver) and **Host** roles.
- **Real-time Map Integration**: Powered by OpenStreetMap (osmdroid) to find nearby chargers without expensive API fees.
- **Dynamic Host Dashboard**: 
    - Individual control for multiple charging stations.
    - Real-time booking request management (Accept/Decline).
    - Earnings tracker and transaction history.
- **Secure Authentication**: Google Sign-In integration for verified users.
- **In-App Wallet**: Simple wallet system for instant payments and host payouts.
- **Multilingual Support**: Designed for accessibility across different regions.

## 🛠️ Tech Stack

- **Platform**: Android (Native)
- **UI Framework**: Jetpack Compose
- **Backend**: Firebase (Authentication & Firestore)
- **Maps**: osmdroid (OpenStreetMap)
- **Language**: Kotlin

## 🚀 Getting Started

### Prerequisites
- Android Studio Ladybug or later.
- A Firebase Project (Google-services.json required).

### Installation
1. Clone the repository.
2. Add your `google-services.json` to the `app/` directory.
3. Sync Gradle and run the app.

## 🤝 Community Impact
By enabling local shopkeepers and homeowners to become charging hosts, EV-Grama creates a new micro-economy while accelerating the adoption of sustainable transportation in India's heartlands.
